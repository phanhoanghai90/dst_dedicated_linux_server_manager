Cấu hình server (cluster.ini)

Khởi động lại server sau khi lưu để áp dụng. Nhớ mở các port UDP ở firewall của nhà cung cấp VPS.

Xoá server

Server phải đang tắt. Thế giới được sao lưu lần cuối vào /root/dst/data/backups/<tên> trước khi xoá.

Cluster Token

Trạng thái: -

  1. Mở Klei Accounts → Game Servers và đăng nhập (bằng tài khoản Steam sở hữu DST).
  2. Đặt tên rồi bấm Add New Server.
  3. Copy chuỗi token (dạng pds-g^KU_...) rồi dán vào ô bên dưới.

Mod của server

Chọn một mod để xem và chỉnh tuỳ chọn.

Giống màn hình Mods trong game: bật/tắt mod và chỉnh tuỳ chọn, rồi bấm Lưu thay đổi (ghi vào modoverrides.lua, dùng chung cho Master và Caves). Khởi động lại server để áp dụng.

Danh sách mod Workshop (để server tải về)

Mỗi dòng một ID hoặc link Steam Workshop. Thêm mod mới ở đây, lưu, rồi bấm Tải mod về để cấu hình được ngay ở bảng trên.

Nâng cao: sửa tay modoverrides.lua

Mod chỉ chạy khi có ["workshop-ID"] = { enabled = true } ở đây. Nếu có thay đổi chưa lưu ở bảng trên, hãy lưu trước khi sửa tay.

Upload thế giới từ máy của bạn

  1. Trên máy tính, mở thư mục save của DST:
    Windows: Documents\Klei\DoNotStarveTogether\<dãy số>\Cluster_N
    macOS: ~/Documents/Klei/DoNotStarveTogether/<dãy số>/Cluster_N
    (Cluster_N ứng với ô thế giới thứ N trong game; mở cluster.ini để xem tên.)
  2. Nén cả thư mục Cluster_N thành file .zip.
  3. Tắt server, rồi chọn file và bấm Upload. Thế giới hiện tại sẽ được tự động sao lưu trước.

Token và port của server luôn được giữ nguyên. Mod trong modoverrides.lua của thế giới sẽ được tự thêm vào danh sách tải.

Tải về chơi local

Tải thế giới hiện tại kèm hướng dẫn (README.txt), danh sách mod và script chạy server trên Windows. Có thể chơi bằng Host Game trong game hoặc chạy dedicated server trên máy mình. Nếu server đang chạy, thế giới sẽ được lưu (c_save) trước khi đóng gói.

Bản sao lưu

Giữ tối đa 20 bản gần nhất. Tải bản sao lưu về để chơi tiếp ở máy local: giải nén và chép thư mục bên trong vào thư mục save của DST.

Thế giới mặt đất (Master/worldgenoverride.lua)

Chỉ có hiệu lực khi tạo thế giới mới (lần đầu chạy hoặc sau khi "Tạo lại thế giới"). Ví dụ overrides: day = "longday", season_start = "spring", world_size = "huge".
